# 奶蛙 / Naiwa Pet (fan-made)

A downloadable animated pet sprite sheet based on the yellow 3D character called 奶蛙 (Naiwa), assembled from the user's supplied visual references.

## Files

- `naiwa-pet-spritesheet-v2.png` — transparent 1536 × 2288 PNG, 8 × 11 cells, 192 × 208 px per cell. Includes nine standard animation rows and two look-direction rows.
- `laugh-preview.gif` — preview of the five-frame belly-laugh loop used for the hover/jump state.

## Use

Download the PNG from this repository or the release ZIP. The sheet follows the ChatGPT Pets v2 sprite-sheet layout. It is intended for compatible animated-pet clients.
